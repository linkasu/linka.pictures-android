# Контракт `.linka`

Набор — одиночный незашифрованный ZIP с UTF-8 `config.json` в корне.
Поддерживаются версии `1.0`, `1.1`, `1.2`, `1.3`; неизвестная версия отклоняется.
Новая версия формата этим изменением не вводится.

Поля manifest и значения при отсутствии поля:

| Поле | Тип | Значение по умолчанию |
| --- | --- | --- |
| `version` | строка | `1.0` |
| `rows` | целое, 1–32 | 3 |
| `columns` | целое, 1–32 | 4 |
| `withoutSpace` | boolean | false |
| `cards` | массив, не более 10 000 элементов | пустой |

Карточка содержит `id` (целое, по умолчанию 0), `cardType` (целое 0–3,
по умолчанию 0), nullable-строки `title`, `imagePath`, `audioPath` (по умолчанию null).
Типы: 0 — обычная карточка, 1 — пробел, 2 — пустая карточка, 3 — placeholder
редактора. При сохранении placeholder становится пустой карточкой; модель редактора
при этом не изменяется. Пустые media paths старых наборов нормализуются в null.

Ссылки на медиа — относительные ZIP-пути с `/`; вложенные каталоги поддерживаются
при открытии и сохранении. Запрещены абсолютные пути, пустые компоненты, `.`/`..`,
обратные слеши, двоеточия и управляющие символы. Указанный файл должен существовать
и не может быть `config.json`. Дублирующиеся ZIP-пути, symlink и конфликт
«файл вместо родительского каталога» отклоняются до распаковки.

Лимиты: вход и суммарный распакованный объём — 512 MiB, один media-файл —
64 MiB, `config.json` — 8 MiB, число ZIP entries — 10 000, central directory —
1 MiB. Проверяются объявленные размеры, metadata до создания списка заголовков
Zip4j и фактические байты потоков. Число ячеек проверяется без переполнения.

Неизвестные дополнительные JSON-поля игнорируются и, как в прежней Android-версии,
не сохраняются. При сохранении набор содержит конфигурацию и только используемые
карточками медиа. При ошибке до атомарной замены прежний архив не меняется.

Контракт проверяют `BoardCodecTest`, `BoardArchiveContractTest`,
`SetsManagerAtomicTest` и `ArchiveIntegrityInstrumentedTest`, включая шесть
настоящих встроенных наборов и вложенные пути.
