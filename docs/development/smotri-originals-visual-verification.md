# Исходные наборы «Смотри»: компоновка и доказательства

7 ноября 2026. Native screenshots, технический gate и user approval — отдельные
проверки. Production Android остаётся legacy; V15 этим не закрывается.

## Изменения

**Действующий детский контракт:** вся страница целиком, без прокрутки сетки и
диагностики на экране ребёнка. Предыдущие результаты ниже проверяли другую
компоновку и не закрывают V14. Новый native-срез должен для каждого набора
зафиксировать все страницы в одном viewport либо отказ взрослому до открытия.
Отказ сохраняет прежнюю доску, курсор, режим и фразу. Несовместимый масштаб текущей
доски не применяется и не сохраняется; остальные наборы проверяются при открытии.
Сохранённые размеры, порядок, EMPTY/SPACE и медиа не меняются.

Реализованы единый расчёт всех страниц, фиксированная сетка, footer-листание и
ожидаемое открытие с проверкой ревизии. Проверки не являются визуальным одобрением
пользователя. V15 остаётся отдельным migration-safety admission.
