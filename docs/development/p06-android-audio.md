## Реализовано

- `AndroidAudioBackend` хранит только applicationContext. Один app-local TextToSpeech, Main Looper callbacks/native handles, один atomic active primitive slot без очереди/нового арбитра. Единственный owner arbiter остаётся common AudioCoordinator. SDK utterance UUID отделён от RequestId; callbacks проверяют slot identity, reason и живой worker. Stop/finish захватывают конкретную generation до Main-post, не находят новый request по старому callback.
- Инициализация/доступность TTS реальная. Экспортируются только non-network, installed voices; preferred ID не заменяется. Язык сверяется с фактическим locale установленного voice без alias/region guessing. Null locale использует реальный local default, а не произвольный fallback; отсутствующий default/voice/data даёт VOICE_UNAVAILABLE. setVoice/isLanguageAvailable/последующий actual voice проверяются, глобальные настройки не меняются. SDK missing-data/network errors — unavailable, не сетевой retry. Speak/synthesize await UtteranceProgressListener terminal, не просто SUCCESS постановки в SDK.
- MediaPlayer использует media/speech AudioAttributes, music stream и transient AudioManager focus через API21-compatible API. Подготовка асинхронная, start только у живой generation, suspend завершается по terminal callback. Focus loss/noisy дают INTERRUPTED, без auto resume/volume/TalkBack/Bluetooth permission changes. Новая receiver flag ветка guarded API33; onStop SDK callback API23 не вызывается кодом на API21.
- Permission callback для mic вызывается только явным record. После Completed обязательно проверяется реальное разрешение app package; synthetic success не разрешает mic. AudioRecord создаётся/стартует только после проверки, PCM16 mono16kHz пишется потоком с буферами 2048 samples/4096 bytes в собственный unique empty WAV temp. Actual sample count/header/FD sync до inspection, пустой/частичный/error/cancel не передаётся. Finish точного active ID останавливает read, затем формирует header. Превышение 10min/64MiB — отказ, не молчаливое обрезание.
- Temp выделяется files port с уникальным именем, immutable source не перезаписывается/не удаляется. Synth/record Completed проверяется injected inspection.audio после terminal. До передачи caller temp остаётся у backend. При failed/cancel/old generation он удаляется best-effort; native cleanup завершается до handoff, после передачи нет suspension/cleanup, способных удалить caller-owned файл. Parent scope закрывает admission/engine и отменяет active request. Exceptions cleanup не пропускают остальные release/cancel и не превращают primary failure/cancel/unknown в успех.
- У этого prerequisite нет Activity/foreground shell binding. Фон/выход будущий shell связывает с общим AudioPort.interrupt/request scope cancellation, как требует code-contracts; в backend уже есть точный stop и parent cleanup. Устройства, реальные Activity lifecycle/route и mic не проверялись. Activity-count heuristics и новая публичная lifecycle API не добавлялись.

## Inspector и resource budgets

- Все чтения/streaming decode/record/file IO — IO worker. Source <=64MiB, decode work budget 30s с cancellation/deadline checks между native calls, MediaCodec dequeue timeout 10ms; speak/synthesis/playback terminal deadline 610s, TTS init 10s, record максимум 600s. Это не обещание принудительно прервать зависший OS configure/release; новых фоновых бесконечных jobs/повторов нет.
- Container sniff — реальные bytes, не extension/hint: RIFF/WAVE, Ogg Vorbis identification+page CRC/EOS, MPEG Layer III frames/ID3, AMR-NB frame boundaries, 3GPP ftyp/box sizes. Структурные проверки отвергают truncated prefixes, которые decoder иногда принимает частично. Источник не изменяется и MIME декодеру не форсируется.
- MediaExtractor выбирает ровно один audio track; decoder ищется по действительному format через MediaCodecList. Channel/rate сверяются с реальными AudioCapabilities перед configure. Весь track дренируется до EOS через MediaCodec, проверяются audio/raw output, PCM encoding/rate/channels/buffer ranges; actual decoded frame count <=600s. PCM buffers считаются и discard-ятся, нет AudioTrack и whole-clip byte array. Нулевой PCM не считается успехом.
- Ограничения этой минимальной платформенной реализации: chained/multiplexed Ogg, несколько audio tracks/data chunks, меняющийся output rate/channels, non-3g ISO brands, MP3 free-format/неподдерживаемые trailing tags и PCM encoding вне 8/16/float не объявляются поддержанными. Не делается успешный частичный decode или fallback. Поддержка конкретных WAV/MP3/Vorbis/AMR-NB/3GPP комбинаций зависит от реального Android decoder и остаётся OPEN до fixtures/device proof; FFmpeg/новых codec bridges нет.
- Images: PNG chunk CRC/IEND, JPEG/WebP/GIF termination checks плюс BitmapFactory bounds до allocation: side<=8192, <=16,000,000 pixels. Настоящая decode validation downsample-ится до <=1Mi pixels RGB565 (для animated formats это platform default frame), bitmap освобождается. Это validation, не image preparation/rewrite/полная проверка всех animation frames.
- Ошибки — Problem codes без path/text/exception logs. Cancelled/UnconfirmedCommit не становятся известной failed publication. Stop/delete/release физически best-effort: native OS/media/files adapters должны довести recovery после собственных IO ошибок; физическое удаление при OS отказе здесь не обещается.
