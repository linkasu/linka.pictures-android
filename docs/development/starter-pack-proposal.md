## Аудиоматериалы: LINKa TTS anton

`starter-pack-recordings.csv`: **74 уникальные записи** для 87 озвучиваемых
позиций. Одна запись переиспользуется во всех перечисленных местах; формат
`used_in` — `seedKey:pN:cN`, номер страницы и row-major ячейки с 1.
`ru.eat` / «Есть» — действие приёма пищи, не утверждение существования.
`SPACE`, точка и вопросительный знак — действия ввода, отдельных записей не требуют.
Glyph labels букв не меняются; `speechText` использует названия, например
Ь → «Мягкий знак», Ъ → «Твёрдый знак», Й → «И краткое», Б → «Бэ».
Каждый точный текст, ключ, URL, voice, метод, bytes/SHA и codec validation сохраняет
`assets/starter-pack/audio/manifest.json`. CSV теперь указывает настоящие `.mp3`.
Это новые исходные материалы, **не runtime assets и не готовые .linka**.

`scripts/prepare-starter-audio.py` использует только Python stdlib и уже установленные
ffprobe/ffmpeg. POST JSON `{"text":"...","voice":"anton"}` без API keys;
первый отдельный preflight «Да» дал 200 audio/mpeg, MP3 decode/non-silent PASS.
Pilot «Помоги» primary получен ранее GET: 7341 bytes, SHA256
`c7f5df90c02687060b9fab6e4d3ae0199e67bb26c11e5388a5c9af7930e0749d`;
он переиспользуется без нового запроса и отмечен GET, не POST.
Остальные новые запросы — только POST, последовательно и без retries.
HTTP ошибки (включая 401/402/429), redirect, неверный content type, size/timeout,
несовпадение hash, недекодируемое или silent audio останавливают обработку.
Существующие файлы не перегенерируются; receipt/hash проверяются перед reuse.
Если файл существует без receipt или ранее записанный файл исчез, отказ вместо
угадывания provenance/повторного синтеза. Сетевой timeout 20s, чтение ограничено
60s плюс timeout одного read, размер 2MiB, длина клипа не более 30s.

Воспроизведение процесса (синтез только отсутствующих записей при явном разрешении):

```sh
python3 -B scripts/test-prepare-starter-audio.py
python3 -B scripts/prepare-starter-audio.py --download --preflight
python3 -B scripts/prepare-starter-audio.py --download --pilot /absolute/path/to/verified/pilot
python3 -B scripts/prepare-starter-audio.py
```

Последняя команда — полностью offline проверка без запросов синтеза. Она сверяет
74 ключа/87 позиций с утверждённым словарём, SHA/размеры, ffprobe MP3 stream,
строгое ffmpeg decode и уровень сигнала (peak ≥ −50dB). Наличие сигнала не доказывает
правильность произношения: listening review и native media inspection ещё нужны.
Детерминированы запросы, ключи и проверка сохранённых bytes, **не обещан одинаковый
результат нового синтеза при изменениях сервиса**. Никакой внешней CC0/GPL-лицензии
на полученные MP3 не объявляем; основание этой работы — явный выбор сервиса пользователем.

Четыре основных набора используют prerecorded offline audio. Необязательные
«Буквы» остаются LITERAL со штатным native TTS для целых слов и зависят от доступного
русского голоса. 33 записи названий букв — reference media, не синтез произвольных
слов и не повод заменять LITERAL аудиокарточками. Эта capability не блокирует
четыре основных набора. INTERNET/сетевой сервис в runtime не добавляется.

**Результат получения:** 74 MP3, 567426 bytes: 73 новых POST JSON и 1 переиспользованный
GET pilot «Помоги». Для четырёх основных наборов — 41 уникальный MP3 / 54 позиции /
340533 bytes; для букв — 33 reference MP3. Все файлы — mono MP3 48000Hz,
длительность 0.624–1.44s, строгий decode и non-silent PASS. HTTP/codec ошибок при
batch не было. Отдельный audio manifest: 72376 bytes, SHA256
`2e8b6a4dfa9613edc6fa0553ae7008957027fe8b82d0b855d7071ed2a7a0e885`.
Состояние — **source audio complete, не shipping pack**: прослушивание и native
media validation ещё не завершены. Изображения и archive candidates подготовлены
отдельным этапом ниже.

## Исторические ограничения и текущие blockers shipping

1. **Права старых медиа, перенос не выполняется:** `linka.looks-electron/README.md:96–102` прямо исключает изображения,
   звуки и учебные материалы из GPL-декларации кода. `THIRD_PARTY_NOTICES.md` не
   содержит media-лицензий этих наборов; внутри проверенных ZIP-кандидатов только
   config и медиа, нет license/provenance. Требуется подтверждение правообладателя
   на конкретные файлы/записи, переработку и поставку Android/iOS с нужной атрибуцией,
   либо новые материалы с явным разрешением. Не объявляем их GPL/CC0 по догадке.
2. **Исторический результат инвентаризации, не текущий источник аудио:** поиск точных title/audioText
   всех 33 архивов после trim/casefold/NFC не нашёл «нет», «не хочу», «помоги»,
   «больно», «мне плохо», «плохо», «хорошо», «ещё», «хватит», «не понимаю».
   «Да» встречается в «Алфавит», «хочу» — в двух идентичных «Фраза».
   Это доказательство отсутствия подписанных кандидатов, не транскрипция всех MP3.
   Старый pain имеет «БОЛИТ», «ПОМОГАТЬ», «СТОП», но не даёт прав и полного покрытия.
   Поэтому пользователь выбрал новый синтез anton, а не перенос старых записей.
   `audioVoice=alena` — лишь метаданные части файлов, не подтверждённый диктор,
   происхождение TTS или разрешение перераспространения. SpeechSource.None и
   требующий установки системный голос не выполняют требование офлайн-речи.
3. **Состав утверждён**, изображения прошли technical review primary; human visual,
   clinical/usability approval и listening review ещё не выполнены.
   «Есть» означает еду; отказ/помощь/боль находятся на первой странице.
   Для необязательных букв штатный native TTS требует доступного голоса;
   четыре основных набора используют записи без этой зависимости. Image assets
   больше не заблокированы: использован новый Codex путь с явным provenance.
4. **Медиа gate после прав:** выбранные .linka прочитать штатным codec и native
   media inspection обеих платформ без ослабления правил. Новые материалы прошли
   PNG structure/raster/hash/bounds и strict MP3 decode, ZIP/wire проверены тестами;
   это не native media PASS. У повреждённого звуки2 CRC также проходит — CRC недостаточно.

Разрешённая исправленная копия звуки2 описана в
`smotri-originals-visual-verification.md:100–114`: SHA256
`a67647676804d4e016d06af694fb04b300abcb5511ea3243a3ee65c02681afcd`.
Это documentary reference, не новый проверенный артефакт этой ветки. Оригинал SHA
`442ca5eb2a6381d63488547e82d957f541a416e04ffea2e56705b861cd24227b`
не использовать. Исправление декодирования не решает вопрос прав.

**Следующее действие primary:** проверить звучание синтезированных реплик;
получить human visual/usability approval и выполнить штатную codec/native проверку
пяти archive candidates. Состав повторно утверждать не требуется.
`shippingResources=[]`: новый runtime комплект не подключается этой веткой.
Нет новых зависимостей или интеграции S10,
изменений bootstrap/storage/Gradle/CI/catalogue, очистки или замены пользовательских
данных. На обновлении библиотека остаётся прежней; seed только для новой установки
после отдельной safety-интеграции primary.
