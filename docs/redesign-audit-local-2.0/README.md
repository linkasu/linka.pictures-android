Дата: 4 ноября 2026 года. **Только обследование и документация, без изменения приложения.**

Скриншоты недоступных окон не имитировались.

## Среда и воспроизводимость

Физических устройств не было. С разрешения пользователя созданы два независимых чистых AVD; профиль `bproxy_api35` и его данные не использовались.

| Параметр | Телефон | Планшет |
| --- | --- | --- |
| AVD | `linka_audit_phone` | `linka_audit_tablet` |
| Serial во время обхода | `emulator-5554` | `emulator-5556` |
| Android | 15 / API 35, Google APIs, arm64 | 15 / API 35, Google APIs, arm64 |
| Экран | 1080 × 2400, 420 dpi | 1600 × 2560, 320 dpi |
| Окно, приблизительно | 411 × 914 dp; в альбоме 914 × 411 dp | 800 × 1280 dp; в альбоме 1280 × 800 dp |
| Язык приложения | `ru-RU` | `ru-RU` |
| Язык Android | Английский | Английский |
| Тема / масштаб | Светлая, штатный размер шрифта | Светлая, штатный размер шрифта |

Основная библиотека снята на телефоне в портрете и на планшете в альбоме; дополнительно снят портрет библиотеки планшета. Доска и редактор сами запрашивают альбомную ориентацию. Настройки, Android picker и возвращение в библиотеку могут иметь другую ориентацию; оригиналы сохранены без поворота или обрезки. Набор снимков не является полной матрицей всех экранов в обеих ориентациях.

Установлена debug-сборка `su.linka.pictures`, версия 2.0 / versionCode 6:

- Исходный commit: `25a6fc07efc537bad524fa97c39dc2e51edaa203`.
- Сборка: `./gradlew :app:assembleDebug` — успешно.
- APK: `app/build/outputs/apk/debug/app-debug.apk`.
- SHA-256: `cd8a6b4ee977b05c29877cb7355da251aef99e65b376ce70aeadba3b8898d339`.

Навигация, скриншоты и дерево интерфейса получены через ADB MCP. Оценка выполнена по самим изображениям, не только по исходникам или текстовому дереву. PNG не ретушировались и не заменялись макетами.

На начальном этапе процессы эмуляторов завершались с SIGABRT как в SwiftShader Indirect, так и в host GPU. Дальнейший обход выполнен в программном `swiftshader` с отключёнными Vulkan / WiFiPacketStream. Это проблема тестового окружения, **не доказанный сбой приложения**. Обрезание названий библиотеки сохранилось после смены графического режима; аппаратная воспроизводимость отдельно не проверена.

## Приоритеты будущего редизайна

1. **P1 — доступность основной функции.** Нормальная ширина формы карточки (26–27, 33), целые названия (02), читаемые системные значки. На телефоне карточки и произнесение должны быть доступны одновременно (13–15, 18, 20).
2. **P1 — безопасность решений.** Конкретные названия объектов и действий в удалении, замене, выходе: никаких двусмысленных «Готово» и «Выйти из сохранения» (05, 09, 29, 31).
3. **P2 — компоновка под задачу и размер.** Отдельная область сетки, компактные параметры редактора, устойчивые фраза/пагинация и сохранение. Проверить, что добавление карточки не выталкивает всё содержимое экрана.
4. **P2/P3 — единый язык интерфейса.** Одни термины, отступы, кнопки и переключатели вместо смеси сиреневого Compose, жёлтых полей и бирюзовых старых диалогов. Ограниченная ширина текстовых форм на планшете.
5. **До завершения будущего редизайна.** Повторный проход недоступных состояний; физический телефон/планшет, крупный шрифт, TalkBack и проверка с пользователями AAC. Сохранить знакомые изображения и позиции карточек; не сокращать зоны касания ради плотности.

## Тестовые данные и ограничения

- Работали только новые тестовые установки со встроенными демонстрационными наборами; личных данных в кадрах нет.
- Создан пустой черновик `Audit`, затем отброшен. Существующий «ХОЧУ» открыт на редактирование, изменения не сохранялись.
- Для родительской проверки задан тестовый пароль и затем штатно выключен контроль. Аналитика оставлена выключенной.
- Для импорта/экспорта в Downloads создан `цифры.linka`; замена существующего набора отменена.
- В конце на этих двух AVD удалены только установленные в рамках аудита демонстрационные наборы для снимка пустой библиотеки. Данные других AVD/устройств не изменялись. Эмуляторы остановлены; тестовые профили оставлены для воспроизведения.
- Unit/instrumentation-тесты не запускались: это визуальный аудит, исходники и конфигурация приложения не менялись. Проверены целостность PNG и ссылки на все снимки в документации.

На этом обследование остановлено. Реализация редизайна, исправление найденных дефектов, новые компоненты и публикация изменений не выполнялись.
